========================================
   Android Mirror - Portable Version
========================================

📌 HOW TO RUN:

1. BEST (No console at all):
   Double-click "AndroidMirror.vbs"

2. Double-click "launch.bat"
3. Double-click "start.bat" (silent)

4. Create Desktop Shortcut:
   Double-click "create_shortcut.vbs"
