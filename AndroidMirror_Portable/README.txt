# Android Mirror - Cara Penggunaan

1. Aktifkan USB Debugging di HP Android
2. Colok HP ke komputer via USB
3. Double-click launch.bat
4. Pilih device dan klik START MIRRORING

Untuk koneksi WiFi:
- Konek via USB dulu
- Klik WiFi Connect dan masukkan IP HP

Shortcuts:
- Kiri: Tap
- Kanan: Back
- Tengah: Home
- Drag: Swipe
- Keyboard: Typing langsung
